# 射频工具箱（微信原生小程序）

无需 npm 构建、无需服务器或第三方组件。使用原生 WXML、WXSS、JavaScript，供微信开发者工具稳定版导入。

## 导入与上传

1. 如使用 ZIP，先解压。打开微信开发者工具稳定版，选择「小程序 → 导入项目」。
2. 项目目录选择包含 `project.config.json` 的文件夹；开发模式选择「小程序」。
3. 调试可使用工具提供的测试号；配置中 `touristappid` 仅用于游客调试。如果当前工具不提供测试号，请使用自己的小程序 AppID。
4. 正式预览、真机测试和上传时，填写**小程序 AppID**（不是公众号 AppID）。可在导入界面填写或修改 `project.config.json` 的 `appid`。
5. 点击「编译」，确认四项工具可切换、输入可实时计算、复制结果正常；点击「预览」进行真机验证。
6. 使用有权限的微信账号登录开发者工具，点击「上传」，填写版本号与说明。之后在微信公众平台的小程序后台提交审核并发布。上传与发布需账号权限，游客 AppID 不能上传。

不需要「构建 npm」，不需要配置服务器域名，不需要关闭域名或证书校验。公众号关联小程序需在微信公众平台按账号支持的关联规则配置。

## 功能

- dBm、W、mW 双向功率换算，支持负 dBm。
- dB、功率比、电压比换算（电压比假设阻抗相同）。
- Hz、MHz、GHz 与 m、cm、mm 自由空间波长换算。
- 驻波比、回波损耗、反射系数幅度换算，显示反射功率占比。
- 实时计算、输入范围提示、示例恢复、复制结果与转发。

切换单位时会加载对应示例。支持 `1e-3` 科学计数法；空输入、无效字符、不合法范围及数值溢出会提示错误，不显示旧结果。显示保留约 10 位有效数字，计算使用 JavaScript 双精度浮点数。

## 验证

安装 Node.js 18 或更新版本后，在项目目录执行 `npm test`，无依赖安装步骤。测试覆盖公式、全部输入单位、边界、错误处理、页面事件和项目配置。

当前云端不含微信开发者工具 GUI，自动测试不能代替微信运行时及真机验收。上传前在开发者工具稳定版及真机核对：30 dBm = 1 W；0 dBm = 1 mW；20 dB = 100 倍功率；299.792458 MHz = 1 m；VSWR 3 = 25% 反射功率。检查复制按钮、工具切换、长数字展示以及非法输入提示。

## 项目结构

`pages/index/` 为工具界面；`utils/rf.js` 为计算模块；`tests/` 为 Node 自动测试。开发者工具上传配置排除了测试和说明文件。
